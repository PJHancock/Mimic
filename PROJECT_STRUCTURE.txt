Key Design Principles
====================

1. INDEPENDENT DEVELOPMENT
   - Each subsystem (vision, tracking, robot) in its own folder
   - Minimal cross-module dependencies
   - Clean interfaces via __init__.py exports

2. SHARED INTERFACES
   - Common data types in src/mimic/common/types.py
   - Central config in src/mimic/config.py
   - Experiment configs in configs/

3. MODULARITY
   - Vision module outputs ActionPrediction → feeds into robot
   - Tracking module outputs HandTrack/ObjectTrack → feeds into robot
   - Robot module orchestrates action execution

4. REPRODUCIBILITY
   - Cached embeddings for fast iteration
   - Config-driven experiments
   - Dataset splits prevent leakage
   - Results stored with configs

5. TESTING
   - Unit tests per module
   - Integration tests verify module boundaries
   - Tests mirror src/mimic structure

Development Workflow
===================

1. Pick a subsystem (vision, tracking, robot, etc.)
2. Create your feature branch: git checkout -b feature/your-feature
3. Work in your subsystem folder with minimal interference
4. Write tests in tests/test_<module>/
5. Run: pytest tests/test_<module>/
6. Commit with clear messages
7. Create PR with explanation

Getting Started
==============

1. Read: README.md (overview) → docs/PROJECT_OVERVIEW.md (specification)
2. Setup: Follow docs/SETUP.md
3. Explore: Check notebooks/ and scripts/
4. Contribute: Follow CONTRIBUTING.md

Quick Commands
==============

pytest tests/                      # Run all tests
python scripts/train_temporal_model.py --config configs/default.yaml
python scripts/run_inference.py --video data/raw/demo.mp4
python scripts/simulate_robot.py --task-file outputs/task.pkl

Shared Code Locations
====================

All shared code should live in:
- src/mimic/common/types.py      → Add new data types here
- src/mimic/common/constants.py   → Add shared constants here
- src/mimic/config.py             → Central configuration

Cross-module code that doesn't fit above → src/mimic/utils.py (if needed)
