🎯 Job Description

Robot Learning Intern - Manipulation Policy Learning

Join Anyware Robotics as a Robot Learning Intern and work on cutting-edge visual imitation learning for robotic manipulation. You'll contribute to building robust action recognition systems that learn from human demonstrations, bridging the gap between computer vision, machine learning, and robotics.

Company: Anyware Robotics
Position: Learning Intern
Duration: Fall 2026
Focus: Policy Learning

Key Responsibilities

📹 Video Processing

Process raw video demonstrations and extract meaningful features for learning

👁️ Object Tracking

Implement computer vision techniques to track objects throughout demonstrations

🧠 Feature Learning

Work with self-supervised learning models to extract visual embeddings

🔍 Action Classification

Train temporal classifiers to recognize robot skills from video features

🎮 Robot Control

Integrate learned policies with robot simulation and execution systems

🎵 Multimodal Learning

Combine audio and visual information for improved skill recognition
